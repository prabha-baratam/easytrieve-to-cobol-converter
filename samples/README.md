# Sample Easytrieve Input Files\n\nThis directory contains sample Easytrieve programs that can be converted to COBOL using the conversion agent.\n\n## Files\n\n### sample1.et\n**Description**: Employee records with salary filtering\n- Reads employee data (ID, Name, Department, Salary)\n- Displays employees with salary > 50000\n\n### sample2.et\n**Description**: Sales data processing with conditional logic\n- Reads product sales data (ID, Quantity, Price, Amount)\n- Displays high-volume products or low inventory warnings\n\n### sample3.et\n**Description**: Customer tier classification\n- Reads customer records with credit limits\n- Classifies customers into tiers (PLATINUM, GOLD, STANDARD)\n- Demonstrates nested IF logic\n\n### sample4.et\n**Description**: Inventory reorder alerts\n- Reads inventory data\n- Flags items below reorder level\n- Useful for supply chain management\n\n### sample5.et\n**Description**: Order processing with multi-level conditions\n- Reads order data with status tracking\n- Identifies pending high-value orders requiring approval\n- Complex nested conditionals\n\n## How to Use\n\n```bash\n# Convert a sample file\npython -m easytrieve_to_cobol.cli samples/sample1.et -o output/sample1.cbl\n\n# View the output without saving\npython -m easytrieve_to_cobol.cli samples/sample1.et\n```\n\n## Expected Output Structure\n\nEach converted file will contain:\n- IDENTIFICATION DIVISION with PROGRAM-ID\n- ENVIRONMENT DIVISION with FILE-CONTROL entries\n- DATA DIVISION with FILE SECTION (FD) and WORKING-STORAGE SECTION\n- PROCEDURE DIVISION with file operations and logic conversion\n\n## Notes\n\nThese samples demonstrate:\n- Single file handling\n- Basic field definitions (numeric and alphabetic)\n- IF/ELSE conditional logic\n- Nested conditions\n- Simple DISPLAY operations\n\nFor more complex Easytrieve features (multi-file joins, advanced reporting, sorting), the conversion agent may require enhancement.\n
